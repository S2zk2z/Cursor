# Canon FTb QL + FL 50mm f/1.4

## FTb QL — что это

| | |
|---|---|
| Год | ~1971 |
| Тип | Зеркалка, **полностью механическая** |
| Без батарейки | Работают затвор и фокус; **экспонометр — нет** |
| Загрузка | **QL** — плёнку вставляете, доводите до метки, закрываете крышку |
| Байонет | **FD** (FL-объективы тоже встают) |
| Экспозиция | Стрелка в **кружок** в видоискателе |

**Рычаг взвода** — после каждого кадра отводите вправо до упора. Это норма, не поломка.

## FL 50mm f/1.4 — почему он особенный

- Светосила **f/1.4** — в 2 раза светлее, чем f/1.8; фон сильнее размывается
- На открытой диафрагме — **мягкая «винтажная» картинка**; резкость растёт с f/2.8
- Часть экземпляров с **ториевым стеклом** — со временем желтеет
- Оптика хвалится за **контраст и резкость** (см. обзор Миханева на liveviewer)

## Главный нюанс: FL на FTb = stop-down metering

С **FD-объективом** видоискатель всегда яркий — экспонометр смотрит через **открытую** диафрагму.

С **FL-объективом** нужно:

1. Навести резкость
2. **Нажать рычаг предпросмотра ГРИП** (уменьшения диафрагмы) у корпуса
3. Пока держите — крутить выдержку, пока стрелка не в кружке
4. Отпустить, снять

Видоискатель в этот момент **темнеет** — так и должно быть. Привыкнете за 1–2 катушки.

> [!tip] Лайфхак
> Для портретов на f/1.4 часто достаточно выставить выдержку **на открытой** диафрагме один раз при похожем свете, потом только фокус.

## FL vs FD на FTb

| | **FD 50/1.8** | **FL 50/1.4** |
|---|---------------|---------------|
| Светосила | f/1.8 | **f/1.4** (светлее ~⅔ ступени) |
| Боке | хорошее | **сильнее** |
| Видоискатель при настройке | **яркий** (открытая диафрагма) | темнеет на f/5.6+ |
| Экспонометр | открытая диафрагма | **stop-down** на закрытой |
| WYSIWYG | нет, пока не нажмёшь рычаг | **да** на закрытой диафрагме |
| Жёлтое стекло | редко | **часто** (торий) |
| На FTb потом докупить FD? | — | **✅ да**, байонет тот же |

**Stop-down простыми словами:**
- **FD:** видоискатель яркий → крутишь выдержку → стрелка в кружок.
- **FL:** на f/8 видоискатель тёмный → так мерит экспонометр.
- **Лайфхак FL:** фокус на **f/1.4** → закрыть до f/2–f/2.8 → подкрутить выдержку.

## Жёлтизна ториевого стекла

| Вопрос | Ответ |
|--------|--------|
| Это поломка? | **Нет** — возраст торированного стекла |
| Опасно? | **Нет** при обычной съёмке (не разбирать и не шлифовать линзы) |
| На цвете | Тёплый, «старый открытка» оттенок — многим нравится |
| На ч/б | Часто **не мешает**, иногда даже плюс |
| Убрать? | UV: подоконник или UV-лампа на **дни–недели** (не всегда до конца) |
| Чем опаснее жёлтизны | **Haze** (мутность), **плесень**, заедающая диафрагма |

**Жёлтизна ≠ haze.** На просвет к яркому небу: жёлтый, но прозрачный — ок; «мыло» и размытые контуры — плохо.

## Батарейка

- Нужна для **экспонометра**
- Обычно **2× LR44** (или переходник **Wein** под старую ртутную PX625)
- С LR44 стрелка может чуть врать — сверяйте с приложением на телефоне
