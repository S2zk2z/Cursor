# Чек-листы

## Покупка б/у (доставка)

Полный разбор лотов → [[06 - Выбор фотоаппарата. Сводка]]. Тексты продавцу → [[film-camera-dialog#3. Вопросы продавцу (перед доставкой)]].

### Чек-лист перед покупкой

- [ ] Видео: затвор 1/1000 … 1 с
- [ ] Видео: экспонометр (закрыть объектив → стрелка падает)
- [ ] Фото открытой крышки — **светоблоки**
- [ ] Объектив на просвет — **haze** (не путать с жёлтизной)
- [ ] Диафрагма f/1.4–f/16 без заеданий
- [ ] Avito Доставка в **Краснодар**
- [ ] Торг **11–12 тыс.** с учётом светоблоков

**Коротко — 5 вопросов:**

1. Светоблоки меняли? Фото открытой крышки?
2. Видео: затвор на 1/1000, 1/125, 1 с
3. Экспонометр: закрыть объектив → стрелка падает
4. Объектив на просвет — haze или только жёлтизна?
5. Свежие сканы с этой камеры?

**Торг:** 11 000–12 000 ₽ если светоблоки не меняли; 13–14 тыс. если всё обслужено.

## Перед каждой съёмкой

- [ ] Затвор взведён
- [ ] Счётчик кадров не на конце
- [ ] Крышка с объектива снята
- [ ] Ремешок на шее (FTb тяжёлая)

## Осмотр на встрече / в ПВЗ

| Часть | Проверка |
|-------|----------|
| Затвор | Все выдержки, без залипания |
| Экспонометр | Стрелка реагирует на свет |
| Объектив | Просвет, диафрагма, фокус |
| Светоблоки | Поролон целый, не крошится |
| Зеркало | Подушка не липкая |
| QL | Механизм цепляет плёнку |

## Типы камер (из вашего ресёрча)

| Тип | Примеры | Для кого |
|-----|---------|----------|
| Мыльница / компакт | Olympus AF-1, Kodak M35 | Без настроек |
| Учебная SLR механика | **FTb**, K1000, OM-1 | Учиться |
| SLR с авто | AE-1, OM-10, Minolta X-700 | Проще экспозиция |
| Плёночный автофокус | Canon EOS 300, Nikon F80 | Объективы EF/F |

Вы выбрали **механику + характер** — это осознанный путь, не «сложнее = хуже».
