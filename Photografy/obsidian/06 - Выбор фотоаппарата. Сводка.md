## Ваш профиль съёмки

| Что важно | Что это значит для выбора |
|-----------|---------------------------|
| Полумрак, с рук | **f/1.4**; плёнка 400–800 → [[03 - Плёнка и лаборатория]] |
| Сильное боке | f/1.4 лучше f/1.8 |
| Ч/б + тёплый винтаж | **Жёлтый FL** — плюс, не минус |
| УФ-лампа | Можно осветлить ториевое стекло позже |
| Учиться фокусу на f/1.4 | FTb + ручной фокус — нормальный путь |

## FL vs FD — что взять в комплект

Кратко; подробно → [[01 - Canon FTb и FL 50-1.4#FL vs FD на FTb]].

| | **FD 50/1.8** | **FL 50/1.4** |
|---|---------------|---------------|
| Светосила | f/1.8 | **f/1.4** |
| Боке / полумрак | хорошо | **лучше** |
| Удобство новичку | **проще** (яркий видоискатель) | stop-down, темнее |
| Винтаж / жёлтый FL | редко | **часто** |
| Перепродажа комплекта | **легче** | уже рынок |

## Ликвидность и перепродажа

> **FTb — не лидер по инвестиции и не самый ликвидный в линейке Canon.** Плёнка — потребление с возможным возвратом **70–90%**, не рост капитала.

### Два разных вопроса

| | **Ликвидность** | **«Инвестиция»** |
|---|-----------------|------------------|
| Смысл | Как быстро и без потерь **продать** | Вырастет ли цена **со временем** |
| FTb + FL | ⭐⭐⭐ | ⭐⭐ |
| FTb + FD 50/1.8 | ⭐⭐⭐⭐ | ⭐⭐ |

### Сравнение по ликвидности

| Камера / комплект | Ликвидность | Инвест-потенциал | Комментарий |
|-------------------|-------------|------------------|-------------|
| **FTb + FD 50/1.8** | ⭐⭐⭐⭐ | ⭐⭐ | Самый **лёгкий перепродажный** комплект Canon |
| **FTb + FL 50/1.4 жёлтый** | ⭐⭐⭐ | ⭐ | Ниша: ч/б, винтаж |
| **AE-1 / AE-1 Program** | ⭐⭐⭐⭐⭐ | ⭐⭐ | Ликвидны, но часто **переплата** |
| **A-1** | ⭐⭐⭐ | ⭐⭐ | Меньше спроса, чем AE-1 |
| **EOS 5** | ⭐⭐⭐ | ⭐ | **Объективы EF** ценнее body |
| **Olympus OM-1** | ⭐⭐⭐⭐ | ⭐⭐⭐ | Компакт + культ |

**Реалистично:** купил за **12к** → через год продал за **9–11к**, если всё работает.

### Стратегии при выходе

| Цель | Действие |
|------|----------|
| Минимум потерь | FTb + **FD 50/1.8** за **9–11к** |
| Ваш FL 50/1.4 | Покупать комплект **11–12к** |
| «Ликвидный» актив | Позже **чистый FD 50/1.8** — проще продать отдельно |

Что держит деньги в плёнке: **объективы** (FD 50/1.4 без жёлтизны, 35/2, 85/1.8), редкие body (OM-1, FM2). Массовые body вроде FTb — **не инвестиция**.

## Совокупная оценка (все факторы)

> **Взвешенная сумма** под профиль: полумрак, боке, ч/б, винтаж, бюджет 10–18к, хобби — не спекуляция.

### Матрица

| Фактор | Вес | FTb + FL 1.4 | Конкурент |
|--------|-----|--------------|-----------|
| Картинка (боке, винтаж, ч/б) | **высокий** | ⭐⭐⭐⭐⭐ | EOS 5 — чище, не ваш стиль |
| Ручной свет / обучение | **высокий** | ⭐⭐⭐⭐⭐ | AE-1 Program — проще |
| Слабый свет, с рук | **высокий** | ⭐⭐⭐⭐ | EOS 5 + AF — **движение** |
| Цена / value | **высокий** | ⭐⭐⭐⭐ *при 11–12к* | FTb + FD 1.8 — дешевле, не ваш визуал |
| Риск покупки | средний | ⭐⭐⭐ | FOTOCCCP — гарантия, +5–6к |
| Ликвидность | средний | ⭐⭐⭐ | AE-1 + FD 1.8 |
| «Инвестиция» | **низкий** | ⭐⭐ | Не решающий |

### Где FTb не первый

| Задача | Лучший вариант |
|--------|----------------|
| Перепродажа | AE-1 + FD 50/1.8 |
| Спокойствие новичка | AE-1 Program в FOTOCCCP |
| Движение, улица | EOS 5 + объектив |
| Минимум денег | FTb + FD 1.8 за ~11к |
| Гарантия | FOTOCCCP (переплата) |

### Условие «победы»

| Условие | Почему |
|---------|--------|
| Цена **≤ ~12–13к** | Выше — AE-1 Program или EOS 5 выгоднее |
| Объектив без сильной мути | Иначе «винтаж» = брак |
| Готовность к stop-down и f/1.4 | Иначе AE-1 Program проще |

При **15–17к** совокупность **ломается**.

### Вердикт

**FTb + FL 50/1.4 при 11–12к — самый сбалансированный пакет** из разобранных. Шаг: торг по [первому лоту](https://www.avito.ru/moskva/fototehnika/canon_ftb_qlcanon_fl_50mm_1.4_i_8211818713) + [[05 - Чек-листы]].
