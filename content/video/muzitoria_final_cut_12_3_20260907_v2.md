## Звук: убрать шипение / «аналоговый шум»

Сначала на съёмке: MANUAL + LINE + низкий gain камеры (см. shoot v4). В FCP — дочистка.

### Порядок в инспекторе Audio

1. Выделить клип на таймлайне → Inspector → **Audio**.  
2. Если стерео/два компонента — раскрыть **Audio Configuration**, править **компонент** (канал), не только клип.  
3. **Audio Enhancements:**
   - **Voice Isolation** — первый выбор для говорящей головы. Amount **40–70%**; не на 100% (металл / «робот»).  
   - **Не** крутить одновременно сильно Voice Isolation **и** Background Noise Removal — выбрать одно.  
   - **Hum Removal** — **50 Hz** (РФ), если гул сети/светильников.  
   - **Loudness** — в конце: Amount умеренно, чтобы речь ровная.  
4. Цель по громкости Reels: примерно **−14…−16 LUFS**, пики **−1…−3 dBTP**.

### Если камерный трек всё ещё шипит

1. Положить бэкап с **TX Synco** под картинку.  
2. Синхронизация: клип + аудио → выделить → **Synchronize Clips** (по звуку) или вручную по хлопку / первой фразе.  
3. Отключить звук камеры на клипе (или Audio Configuration → выкл камерные каналы).  
4. Лёгкий Voice Isolation на TX-дорожке при необходимости.

### Музыка под голос

- Эмбиент / гитарный луп **−18…−20 dB** относительно голоса.  
- На CTA можно чуть поднять музыку на 1–2 dB.

## Цвет на весь ролик сразу (не по клипам)

В FCP коррекция висит на **клипе**. Чтобы красить весь таймлайн одним слоем — три рабочих способа.

### 1. Adjustment Clip (предпочтительно)

1. Effects → искать **Adjustment Clip** (или Titles → *Custom* пустой титр на всю длину — старый хак).  
2. Положить **Adjustment Clip** на дорожку **выше** всего видео, растянуть от первого до последнего кадра.  
3. Выделить Adjustment Clip → Inspector → **Color** / Color Board / Color Wheels / Curves / Hue/Sat.  
4. Все клипы **под** ним получают одну и ту же коррекцию.

Плюс: можно выключить слой одним кликом; B-roll и лицо красятся одинаково.  
Минус: если одному крупняку нужна другая экспозиция — правьте тот клип снизу (локально) поверх общего слоя.

### 2. Compound Clip

1. Выделить **все** видеоклипы на таймлайне (A).  
2. **File → New → Compound Clip** (⌥G).  
3. Красить уже **compound** как один клип.

Плюс: один объект. Минус: внутрь compound заходить для точечных правок неудобнее, чем с Adjustment Clip.

### 3. Скопировать цвет на выделенные клипы

1. Покрасить один эталонный клип.  
2. ⌘C → выделить остальные → **Edit → Paste Attributes** (⇧⌘V) → галка **Color** / нужные эффекты → Paste.

Удобно для серии одинаковых take; для «весь ролик одним взглядом» лучше п. 1.

### Практика для Muzitoria

- Снято на **Eterna / Classic Chrome** → на Adjustment Clip лёгкие Exposure / Contrast / Saturation, без тяжёлого LUT «ради кино».  
- Свет P160C уже задал базу — в посте чаще **выровнять** лицо и витрину, не перекрашивать.  
- Проверять скин на говорящей голове и блик на лаке гитары отдельно после общего слоя.
