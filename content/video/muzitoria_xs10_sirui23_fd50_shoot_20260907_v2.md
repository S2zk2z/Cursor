## Базовые настройки X-S10 (видео)

### Файл и картинка

| Параметр | Значение | Коммент |
|----------|----------|---------|
| Режим | **Movie** / F-Log off для быстрых соцсетей | Для Inst/TG/VK — сразу «готовая» картинка |
| Film Simulation | **Eterna** или **Classic Chrome** | Eterna мягче для монтажа; Chrome — характернее витрины |
| Разрешение | **4K 25p** (мастер) → кроп в вертикаль; или **1080p 25/50** если греется | Мастер один, нарезки под платформы |
| Битрейт | Максимум доступный | Меньше артефактов на гитаре/хроме |
| Выдержка | **1/50** при 25p (180° shutter) | Днём — ND / прикрыть диафрагму |
| ISO | Авто с потолком **3200–6400** или фикс 800–1600 в зале | Не гнать шум в тенях витрины |
| WB | Кельвины по свету зала (часто **4000–4800K**) | Не Auto при смешанном свете |
| IBIS | On | Для Sirui указать **23 mm**; для FD — **50 mm** вручную |
| Фокус (Sirui) | AF-C + Face/Eye | Для говорящей головы |
| Фокус (FD 50) | MF + focus peaking | Медленные панорамы, не «охота» |

### Кадр

- **Вертикаль 9:16** — основной мастер для Inst / TG / VK / Shorts.
- **Горизонт 16:9** — отдельно 1–2 take для YouTube (обзор / «день в магазине»), если нужен длинный ролик.
- Откидной экран на себя — вертикаль на уровне глаз собеседника.
- Оставлять «воздух» сверху/снизу под титры и UI платформ.

## Звук — Synco G3 Pro

**Комплект:** RX (приёмник с экраном) + 2× TX (передатчики) + кабель **3.5 mm TRS → камера** + опц. петлички из комплекта / ветрозащита.

### Подключение к X-S10

1. RX — на горячий башмак или рядом с камерой (клипса / магнит).  
2. Кабель из комплекта: **3.5 mm TRS камера** → разъём mic на X-S10 (не TRRS от телефона).  
3. На RX в настройках выхода: режим **TRS** (камера), не TRRS.  
4. На X-S10: внешний mic активен; уровень mic — так, чтобы пики речи были около **−12…−6 dB** на шкале камеры (без клиппинга).  
5. Наушники в **monitor** на RX — слушать take вживую.

### Рабочие пресеты для зала Muzitoria

| Сцена | TX | На RX | Заметка |
|-------|-----|-------|---------|
| Говорящая голова (1 человек) | **TXA** на груди / воротнике, 15–20 см от рта | Только канал A в миксе / громче A | Ветрозащита даже в помещении — меньше шороха одежды |
| Диалог консультант + клиент | **TXA** + **TXB** | Оба канала; балансировать на экране RX | Клиент тоже в петличке — иначе «зал съедает» |
| B-roll без речи | Mic off / уровень вниз | Или писать только ambient на камеру | Не оставлять открытый TX на шуршащей куртке |

### Настройки G3 Pro (старт)

- **ANC:** Low или Medium в зале с гулом кондиционера; High — только если очень шумно (может «съесть» естественность).  
- **Low-cut:** включить, если гул от холодильников/вентиляции.  
- **Gain на TX:** начать с среднего; лучше чуть тише на TX и поднять на RX/камере, чем клип на передатчике.  
- **Внутренняя запись на TX (бэкап):** **включить** на говорящей голове — страховка от обрыва 2.4 GHz / случайного выдёргивания кабеля.  
- Заряд: RX ~10 ч, TX ~5 ч — перед днём полный заряд; запасной пауэрбанк USB-C.

### Чеклист звука (2 минуты)

- [ ] TXA/TXB спарены с RX (индикация на экране)  
- [ ] Кабель **TRS camera**, не телефонный TRRS  
- [ ] Тест 10 с речи → смотреть уровни на **RX и на X-S10**  
- [ ] Нет клиппинга при громком «раз»  
- [ ] Шуршание одежды: переложить клипсу / подложить ткань  
- [ ] Музыка в зале выкл или −20 dB к голосу  
- [ ] Бэкап-запись на TX включена (для ключевых take)

## Когда какой объектив

### Sirui 23/1.2 — «лицо магазина»

- Хозяин / консультант говорит в камеру.
- Средний план: человек + гитары за спиной (зал читается).
- Обходы витрины с рук (IBIS + f/1.4–2.0).
- Рабочая дырка для говорящей головы: **f/1.4–2.0** (резкое лицо, мягкий фон).  
  Для «весь зал резкий» — **f/4–5.6**.

### Canon FD 50/1.4 — «тактильность»

- Пальцы на ладах, анкер, колки, струны крупно.
- Профиль корпуса, лак, логотип на голове грифа.
- Переход «рука → инструмент → лицо» (медленный rack focus).
- Рабочая дырка: **f/1.4–2.0** для боке; **f/2.8** если критична резкость по плоскости грифа.
- Перед take: peaking + увеличить в EVF/экране → зафиксировать фокус → начать движение.

Снимать «кирпичи» — потом собирать разные длины под платформы.

| # | Шот | Объектив | Звук | Длина | Заметка |
|---|-----|----------|------|-------|---------|
| 1 | Вход / вывеска / дверь | 23 | ambient / off | 5–8 с | Статика или медленный подход |
| 2 | Зал с высоты груди, панорама | 23 | ambient | 8–12 с | IBIS, не дёргать |
| 3 | Говорящая голова (хук + тело + CTA) | 23 | **TXA → RX → X-S10** | 40–60 с × 2–3 take | См. сценарий; бэкап на TX |
| 4 | Консультант + клиент (гитара в руки) | 23 | **TXA + TXB** | 10–20 с | Живой жест, без «рекламы» |
| 5 | Руки на грифе / медиатор | FD 50 | off или тихий TX | 8–10 с | f/1.4–2, peaking |
| 6 | Крупняк головки / логотипа бренда | FD 50 | off | 5–8 с | Боковой свет |
| 7 | Струны + отражение зала | FD 50 | off | 5 с | Можно лёгкий flare |
| 8 | «До / после» настройки | 23 + 50 | TXA | 15–20 с | Процесс, не лекция |
| 9 | CTA-карточка | 23 | TXA или тишина | 5 с | Плашка Taplink |

Итого сырого: ~8–12 минут. Монтаж: 1 вертикальный мастер 35–45 с + укороченные нарезки.

## Свет (магазин)

1. Основной: боковой от окна или мягкий LED сбоку — не кольцо в глаза.
2. Не снимать против яркой витрины без заполнения лица.
3. Хром/лак гитар — следить за бликами; чуть сместить камеру, не убивать блик ND до «пластика».
4. Один спокойный источник + отражение от стен зала лучше, чем три жёстких софита.
