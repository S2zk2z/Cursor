# Fujifilm X-S10 — чеклист приёмки

> [!info] Связка на проверку
> **Камера:** X-S10 (заказ ~51 000 ₽, заявный пробег ~2376)  
> **Объектив:** аренда **Viltrox AF 23/1.4 XF**  
> **Важно:** проверка в первые часы (окно Avito на осмотр)

> [!warning] Снимай доказательства
> Видео распаковки + фото экранов с пробегом/багами. Без этого спор сложнее.

---

## 0. До включения (2 мин)

- [ ] Коробка целая, комплект как в объявлении:
  - тушка
  - родной АКБ
  - зарядка
  - карта Kingston Canvas Go! Plus SDG3 64 ГБ
  - инструкция / талон / чек
- [ ] Серийник на **днище** = серийник на **коробке/чеке**
- [ ] Модель на шильдике: **FF200001** (X-S10)

---

## 1. Первое включение (3 мин)

- [ ] Камера включается
- [ ] АКБ показывает заряд (не 0% сразу после «полного»)
- [ ] Дата/время можно выставить
- [ ] Карта читается; при необходимости **форматни** в камере

### Пробег (самое важное)

**Путь:** `Меню → НАСТРОЙКА (ключ) → листай вниз → «Срабатывания затвора»`

- [ ] Пробег около **~2300–2500** (заявлено ~2376)
- [ ] Фото экрана с пробегом сохранено

Если пункта нет:
1. Сделай 1 JPEG на карту
2. Проверь через EXIF / shuttercount на компе
3. Или приложение Fujifilm XApp

> [!failure] Стоп-критерий
> Пробег сильно больше (десятки тысяч) → сразу в поддержку Avito.

---

## 2. Корпус и механика (5 мин)

- [ ] Кнопки не залипают (Q, MENU, AEL, AF-ON, джойстик, DISP)
- [ ] Колёса режимов / управления крутятся без люфта «в мясо»
- [ ] Байонет: объектив садится плотно, без сильного шатания
- [ ] Контакты байонета чистые
- [ ] Крышка отсека АКБ/карты открывается нормально
- [ ] Горячий башмак без поломки (для mic позже)

---

## 3. Экран (критично для Reels) — 5 мин

- [ ] Откинуть **вверх / вниз / на себя (флип)**
- [ ] Тач работает во всех положениях
- [ ] Нет полос, розовых пятен, битых зон
- [ ] Петля/шлейф не хрустит, экран не отваливается

> [!tip] Зачем
> У X-S10 поворотный экран — основа вертикальных рилсов. Битый шлейф = почти приговор.

---

## 4. Матрица — тест пыли (3 мин)

1. Повесь Viltrox 23/1.4
2. Диафрагма **f/16**
3. Сними **чистое небо** или белую стену / лист
4. На экране увеличь просмотр

- [ ] Нет жирных тёмных пятен
- [ ] Мелкая пыль — часто норм; крупные «blobs» — плохо

Сделай то же **без объектива** (осторожно, коротко) — отличишь пыль на стекле от пыли на сенсоре.

---

## 5. Viltrox 23/1.4 — проверка аренды (10 мин)

### Совместимость
- [ ] На кольце/байонете именно **XF / X-mount / Fujifilm X**
- [ ] **Не** Z / E / RF

### Оптика
- [ ] Просвет на свет: нет грибка, масла на лепестках, дымки
- [ ] Передняя/задняя линза без глубоких царапин

### AF фото
- [ ] AF-S по лицу / глазу цепляет
- [ ] На **f/1.4** и **f/2.8** резкость в центре нормальная (не «мыло»)

### AF видео (Reels)
- [ ] 30–60 сек: смотришь в камеру — фокус не «охотится» постоянно
- [ ] Перевод взгляда ближе/дальше — отрабатывает без истерики

### Прочее
- [ ] Кольцо фокуса без хруста
- [ ] Диафрагма меняется с камеры
- [ ] USB-C на объективе на месте (для прошивки; на аренде можно не трогать)

> [!info] Норма для 23/1.4
> На f/1.4 чуть мягче + возможны лёгкие ХА по краям контраста. На f/2–2.8 должно стать заметно лучше. Полное «мыло» везде — брак/разъюстировка.

---

## 6. Фото-базовый тест (5 мин)

Снять пачку кадров:
- [ ] День у окна: f/1.4, f/2.8, f/5.6
- [ ] Портрет/лицо с AF по глазу
- [ ] Film Simulation: **Eterna** / **Classic Chrome** / **Acros** (на вкус)

Проверить:
- [ ] Файлы пишутся на SD
- [ ] Просмотр на камере ок

---

## 7. Видео / Reels (8 мин)

- [ ] **1080p** 30–60 сек с рук
- [ ] **4K** 2–3 мин — не выключается от перегрева сразу
- [ ] Экран на себя (вертикаль) — удобно кадрировать
- [ ] IBIS: в меню объектива/фокусного укажи **23 mm** (или камера подхватит)
- [ ] Сравнение: кадр с рук ~1/15–1/30 — стаб помогает

Звук:
- [ ] Встроенный mic пишет (для теста хватит)
- [ ] Разъём **3.5 mm** на месте (визуально)

---

## 8. Питание и USB (3 мин)

- [ ] После 20–30 кадров заряд не падает лавиной
- [ ] Зарядка от зарядника работает
- [ ] USB к компу: если ошибка «как у продавца» — **не критично**
  - Рабочий путь: **SD → кардридер**

---

## 9. Быстрый сценарий «наш формат рилсов» (5 мин)

Имитация магазина:
1. Камера на уровне глаз, вертикаль
2. f/1.4–2, человек ближе, фон дальше
3. 20–30 сек «говорящая голова»
4. 10 сек крупняк рук/предмета

- [ ] Лицо в фокусе
- [ ] Фон мягче лица
- [ ] Место сверху/снизу под титры
