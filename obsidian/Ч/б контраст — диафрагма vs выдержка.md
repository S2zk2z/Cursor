# Ч/б контраст — диафрагма vs выдержка

См. также: [[Canon F-1 — плёнка и экспозиция]]

> [!summary] В одном предложении
> **Диафрагма** и **выдержка** задают **сколько света** попало на плёнку. **Контраст** в первую очередь — от **света в сцене** и **проявки**.

## Что реально делает контрастнее

| Способ | Как |
|--------|-----|
| **Жёсткий свет** | Боковое солнце, тени, один источник |
| **Проявка** | Rodinal, дольше в проявителе |
| **Фильтры** | Жёлтый/оранжевый — небо темнее |
| **Печать / скан** | Уровни, кривая |

## Что НЕ делает (напрямую)

- Отдельно «крутить выдержку для контраста» при той же экспозиции
- Отдельно «закрывать диафрагму для контраста» без изменения света

## Косвенный эффект экспозиции

```
Недоэкспозиция  →  тени в чёрный  →  кажется контрастнее, хуже по качеству
Переэкспозиция  →  мягче, больше деталей в тенях
```

|---------------|--------------|
